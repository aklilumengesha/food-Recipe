# 🍽️ Food Recipe App

A simple and responsive web application that allows users to search for meal recipes using the [TheMealDB API](https://www.themealdb.com/). Built with vanilla JavaScript, HTML, and CSS.

---

## 🔍 Features

- 🔎 Search meals by name
- 📋 View ingredients and detailed instructions
- 📸 Displays meal images from the API
- 🎨 Clean and responsive UI
- ❌ Closeable popup for recipe details

- HTML5
- CSS3
- JavaScript (ES6+)
